# Бірқалып · жеке және ортақ бюджет

Қазақша қаржы сайты: айлықтан айлыққа дейінгі күндік лимит пен отбасының ортақ мақсаттары.
Жеке кеңістік пен ортақ кеңістік бір-бірінен бөлінген. Тіркелген топқа жеке операциялар жіберілмейді.

## Іске қосу

Node.js 24 немесе жаңарақ нұсқа қажет. Сервердің сыртқы npm тәуелділігі жоқ.

```sh
cd bir-qalyp
npm start
```

Браузерде `http://localhost:3000` ашыңыз. Негізгі сынақ:

```sh
npm test
```

Браузер сынақтары үшін:

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

Жүйеде Chromium бар болса, `PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/chromium` айнымалысын беруге болады.

## Нақты ортақ бюджет

1. «Ортақ» режимін таңдаңыз. Алғашында мысал деректері бар **демо кеңістік** ашылады.
2. «Нақты ортақ бюджет ашу» арқылы бос серверлік топ жасаңыз.
3. Ортақ нақты қалдықты, резервті және айлық күнін енгізіңіз.
4. «Адам шақыру» батырмасымен сілтемені / QR кодын жіберіңіз.
5. Екінші адам сілтемені ашып, атын енгізеді (мысалда — **Умида**).
6. Ортақ хотелкалар, мақсаттар мен операциялар екі құрылғыда бір серверден көрінеді.

Қатысушылардың экраны шамамен 2,5 секунд сайын жаңарады. Демо режимі тек осы браузерде жұмыс істейді.
QR код нақты шақыру URL мекенжайын қамтиды. Шақыру 7 күнге жарамды; бюджет иесі оны ауыстыра алады.
Бюджетке кіру құқығы құпия кездейсоқ сессия токенімен сақталады; серверде токеннің тек хэші болады.
Шақыру сілтемесін тек қосқыңыз келген адамға беріңіз.

## Мүмкіндіктер

| Жеке бюджет                                   | Ортақ бюджет                               |
| --------------------------------------------- | ------------------------------------------ |
| Шолу және бүгінгі лимит                       | Отбасының ортақ шолуы                      |
| Айлық, жинақ, резерв, міндетті төлемдер       | Ортақ қалдық және резерв                   |
| Шығын / кіріс / өз шоттары арасындағы аударым | Ортақ салымдар мен шығындар                |
| Операцияны түзету, жою, санаттар есебі        | Авторын көрсететін ортақ операциялар       |
| «Сатып алсам ше?» сценарийі                   | Бағасы мен сипаттамасы бар хотелкалар      |
| Жеке есептік / ЖИ кеңес                       | Хотелканы қолдау, сатып алуды шығынға жазу |
| CSV және қалдық болжамы (демо Plus)           | Мақсаттарға жинақ бөлу, босату, жою        |

Төленген міндеттеме екі рет есептелмейді. Хотелка қосу және сатып алуды модельдеу ақша шегермейді.
«Сатып алдық» бір рет шығын жасайды. Мақсатқа бөлінген жинақ күнделікті қолжетімді ақшадан шегеріледі,
ал босату немесе мақсатты жою оны қайтарады. Бұл әрекеттер банк аударымы емес.
Өз шоттарыңыз арасындағы аударым жеке қалдықты өзгертпейді.
Жеке кірісті күнделікті шығынға, жинаққа не резервке бөлуге болады.
Жалақы автоматты түрде кіріс болып есептелмейді. Күндер `Asia/Qyzylorda` уақыт белдеуімен есептеледі.

## Жазылым форматы

**Тарифтер — демо.** Карта енгізу, ақша алу және төлем провайдері қосылмаған.
Бағалар — өнім форматына арналған үлгі; тарифтерді тегін ауыстырып сынауға болады.

|                                           | Free | Plus · 990 ₸/ай үлгі | Family · 1 990 ₸/ай үлгі |
| ----------------------------------------- | ---- | -------------------- | ------------------------ |
| Ортақ қатысушылар                         | 2    | 2                    | 6                        |
| Мақсаттар                                 | 3    | 20                   | 50                       |
| Хотелкалар                                | 5    | 50                   | 200                      |
| Күндік жоспар, операциялар, есептік кеңес | ✓    | ✓                    | ✓                        |
| CSV есеп, қалдық болжамы                  | —    | ✓                    | ✓                        |
| Қосылған генеративті ЖИ қызметі           | —    | ✓                    | ✓                        |

Ортақ топтағы шектеулер серверде де тексеріледі. Ортақ тарифті тек бюджет иесі өзгертеді.
Демо тарифті ақылы жазылым ретінде қолдануға болмайды: production төлем провайдері мен webhook
арқылы сервердегі entitlement тексерісін бөлек іске асыру керек.

## Кеңесші

Кілтсіз есептік алгоритм нақты енгізілген сандарды талдайды; жауапта «Есептік кеңес» деп көрсетіледі.
Генеративті ЖИ үшін серверге `BIRQALYP_AI_KEY` айнымалысын қауіпсіз беріңіз.
Әдепкі модель `gpt-4.1-mini`; оны `BIRQALYP_AI_MODEL` арқылы өзгертуге болады.
Кілт браузерге берілмейді. ЖИ сұрауы нақты серверлік Plus/Family тобының жарамды мүшелігін талап етеді.
Жеке деректерді ЖИ провайдеріне жіберу тек пайдаланушының сұрағынан кейін болады; басқа топ мүшелері оларды көрмейді.
Кілт болмаған, сервис істемеген немесе квота біткен жағдайда есептік кеңес көрсетіледі.
Әдепкі квота: топқа 10 сұрақ/күн, серверге 20 сұрақ/күн.
`BIRQALYP_AI_DAILY_LIMIT` сервердің күндік шегін өзгерте алады (1–1000).
Нақты ЖИ сұрауы осы ортада кілтсіз тексерілген жоқ.

## Хостинг

GitHub-қа кодты сақтау сайтты автоматты жарияламайды. GitHub Pages статикалық жеке/демо нұсқаны
көрсете алады; **екі құрылғының ортақ бюджетіне Node сервері қажет**.
Екі телефон да бір жарияланған сервердің мекенжайын қолдануы тиіс.

Серверлік хостингте:

- Іске қосу командасы: `npm start`, жұмыс каталогы: `bir-qalyp`.
- `PORT`: хостинг беретін порт (әдепкі 3000).
- `PUBLIC_URL`: сырттан ашылатын HTTPS мекенжайы, мысалы `https://birqalyp.example`.
- `BIRQALYP_DATA_DIR`: тұрақты дискідегі деректер каталогы.
- Бір сервер процесін қолданыңыз: JSON сақтау бірнеше репликаға арналмаған.
- `/api/health` endpoint-і дайындықты тексереді.
- HTTPS reverse proxy арқылы жариялаңыз. Құпия айнымалыларды Git-ке қоспаңыз.

`PUBLIC_URL` шақырулардың дұрыс жария мекенжайын құрайды. Әдепкіде URL ағымдағы сайтқа қатысты жасалады.
Ортақ деректер әдепкі `.data/budgets.json` файлында атомарлы сақталады, сервер қайта іске қосылғанда қалпына келеді.
Бұл каталог Git-ке кірмейді. Тұрақты диск пен сақтық көшірмесін хостингте баптаңыз.

Docker үшін дайын `Dockerfile` бар:

```sh
docker build -t birqalyp .
docker run -p 3000:3000 -v birqalyp-data:/data -e PUBLIC_URL=https://YOUR-DOMAIN birqalyp
```

Docker құрастыруы осы ортада орындалған жоқ.

## Қазіргі шектеулер

- Бір жеке айлық кезең және бір ортақ топ; архив, банк интеграциясы, автоматты қайталанатын төлемдер жоқ.
- Жеке бюджет браузердің localStorage жадында. Оны тазалау жеке жазбалар мен топқа кіру сессиясын жояды.
- Толық аккаунт, парольмен кіру және сессияны қалпына келтіру қосылмаған.
- Жазылым және баға үлгісі төлем қабылдамайды.
- Генеративті ЖИ жеке провайдер кілтін және серверлік тарифті қажет етеді.
- JSON сақтау шағын бір серверлік прототипке арналған; үлкен өнім үшін дерекқор және толық аккаунт жүйесі қажет.
